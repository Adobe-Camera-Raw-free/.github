## 🧠 Overview

Adobe Camera Raw is the raw processing engine behind Photoshop, Lightroom and Bridge: it develops sensor data with tone, colour, detail, lens correction and AI masking, and writes the settings into the file or a sidecar without touching the original pixels.

Published by Adobe. Category: Raw image processing.

The archive in this repository contains the plug-in suite itself plus the integration files for Adobe Photoshop, Adobe Bridge, Adobe After Effects.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎞️ Raw Development | Decodes camera raw formats with per-camera colour profiles and white balance. |
| 🎚️ Tone Controls | Exposure, highlights, shadows, whites and blacks with a live histogram. |
| 🧠 AI Denoise | Reduces high-ISO noise by rebuilding detail from a neural model instead of blurring. |
| 🔍 Super Resolution | Doubles the pixel dimensions and then builds detail into the enlarged result. |
| 🎭 AI Masking | Selects subjects, sky, hair and objects, then refines the mask automatically. |
| 🔭 Optics Correction | Applies lens profiles, chromatic aberration correction and perspective alignment. |
| 🧾 Presets and Snapshots | Settings are stored as presets, and snapshots keep alternative versions inside one file. |
| 🔗 Non-destructive Output | Saves to DNG, TIFF or JPEG while the original raw file stays untouched. |

## Additional Information for Windows Users

The plug-in suite registers itself in Adobe Photoshop, Adobe Bridge during installation, so the host version matters more than the Windows build: update the host application before adding Adobe Camera Raw.

Settings created in Adobe Camera Raw are stored in the plug-in's own preset folder, so a reinstall keeps user presets and replaces only program files.
